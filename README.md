HR Analytics Dashboard created using Microsoft Excel to analyze employee attrition, job satisfaction, performance, salary distribution, and workforce trends through interactive charts, KPIs, and slicers.
Provides actionable HR insights into employee turnover, department performance, hourly rates, and gender-wise income to support data-driven decision-making.
